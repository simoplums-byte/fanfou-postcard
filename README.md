# Fanfou Postcard（饭否明信片）

面向个人用户的饭否（Fanfou）数据备份工具：把你在饭否留下的每一条消息，安全地保存到本地，长期留存。

## 它做什么

- 通过饭否官方 OAuth 1.0 授权，只读导出你的时间线消息
- 以 JSON 作为权威备份格式，尽量保留 API 原始字段，数据可无损迁移
- SQLite、HTML、Markdown、CSV 等索引与查看副本，全部由权威 JSON 生成
- 支持增量更新与断点续传，适合长期持续备份
- 照片与消息归属一并记录，可独立下载

## 设计原则

- **只读**：仅读取当前账号数据，不发布、不删除任何内容
- **JSON-first**：原始字段优先，查看格式不反过来限制数据结构
- **本地优先**：凭据保存在系统钥匙串，不写入仓库、日志或明文文件
- **范围克制**：收藏、私信、好友等数据按权限与隐私单独评估，不默认纳入

## 当前状态

开发中。OAuth 授权链路已验证通过，正在推进应用审核与账号级 API 验证。

## 安全说明

本项目只读取数据，不发布内容；OAuth 凭据与访问令牌仅保存在本机系统钥匙串中，不会写入代码仓库。
